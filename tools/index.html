Comfort Schedule test pages

  • check.html — compiles every Python file, parses the card script and JSON, and unit-tests the schedule logic.
  • emu.html — scenario tests for the controller (Heat/Cool switching, holds, per-block mode and fan, health, runtime, colors).
  • cards.html — all four cards against a mocked Home Assistant. Theme, layout and state switches at the top; service calls are logged.

The Python pages run in the browser with Pyodide (downloaded from cdn.jsdelivr.net on first load). Each page sets its title to done when finished; look for FAIL lines.
